# النفحة النورانية — موقع الطريقة الخلوتية الحامدية

موقع ويب (Front-End) يعرض نص كتاب **«النفحة النورانية في أوراد الطريقة الخلوتية الحامدية»** كاملاً، مع أدوات مساعدة للذكر والتسبيح.

🔗 **رابط الموقع:** https://shoaibshadad8-spec.github.io/al-nafha-al-nourania/

## المميزات

- 📖 **أوراد الطريقة** — كل أوراد وأذكار الطريقة (الإشراق، الضحى، الظهر، العصر، الغروب...) قابلة للقراءة مباشرة، مع تكبير/تصغير الخط والتنقل بين الصفحات (السابق/التالي).
- 📿 **سبحة إلكترونية** — عداد تسبيح تفاعلي بأهداف قابلة للتخصيص (٣٣ / ٩٩ / ١٠٠)، ويحفظ التقدّم محليًا في المتصفح.
- ✦ **اللآلئ السنية** — منظومة سيدي أحمد الدردير.
- 📚 **مكتبة المشايخ** — نص الكتاب كاملاً (٤٨ قسمًا، من المقدمة حتى بيعة الطريق) قابل للتصفح والتحميل كملف نصي واحد.
- 🔎 بحث سريع داخل عناوين الأوراد.
- 📱 **PWA** — يمكن تثبيت الموقع كتطبيق على الهاتف (إضافة للشاشة الرئيسية)، ويعمل جزئيًا بدون إنترنت بفضل service worker.
- 🔗 مشاركة الموقع مباشرة عبر واجهة المشاركة في المتصفح.

## التقنيات المستخدمة

- HTML5 / CSS3 (بدون أي مكتبة تصميم خارجية)
- JavaScript (Vanilla JS) — بدون أي إطار عمل
- PWA: Web App Manifest + Service Worker
- تخزين محلي: localStorage (لحفظ آخر ورد مقروء وتفضيلات حجم الخط وعداد السبحة)

## هيكل المشروع

```
├── index.html          الصفحة الرئيسية وكل الواجهات (SPA بسيط)
├── style.css           التنسيقات (نظام ألوان كحلي/ذهبي)
├── script.js           منطق التطبيق (التنقل، القراءة، البحث، السبحة، PWA)
├── sections.json       نص الكتاب كاملاً، مقسّم إلى أقسام بعنوان ونص
├── manifest.json        بيانات تطبيق الويب التقدمي (PWA)
├── sw.js               service worker للتصفح دون اتصال
└── assets/             الأيقونات وصورة المشاركة (favicon, og-image)
```

## التشغيل محليًا

المتصفح يمنع قراءة `sections.json` بأمر `fetch` عند فتح `index.html` مباشرة من الجهاز (قيود CORS الخاصة بـ `file://`)، فلازم تشغيل سيرفر محلي بسيط، مثلاً:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.

## المصدر

نص الكتاب منسوخ بالكامل من الكتاب المطبوع «النفحة النورانية في أوراد الطريقة الخلوتية الحامدية»، أشار بطبعته فضيلة الشيخ خالد أمير محمد (١٤٤٤هـ / ٢٠٢٢م). هذا الموقع غير رسمي، وهو عرض مبسّط لنص الكتاب لتسهيل الاطلاع عليه ومشاركته.
